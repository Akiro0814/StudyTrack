# iOS 实机反馈修复设计

按用户本轮 8 项明确要求继续实施，大学仍为大一至大四上下学期，旧档案和成绩不迁移或删除。

1. 最近成绩行使用唯一的拖动/轻点手势仲裁，向左拖动露出右侧删除按钮；任何拖动结束均不打开编辑，轻点仍编辑，删除保留撤销。分析明细共用组件。
2. 删除覆盖内容的自制顶部材质矩形，滚动容器采用 iOS 26 原生 soft scroll edge。导航背景由系统管理，保持壁纸背景。
3. 无用户档案的首次启动展示三页引导：记录、分析、备份；可跳过，随后填写头像、姓名、阶段和学期。创建档案后不再显示；设置提供重新查看入口。
4. 云备份采用两种兼容渠道：已有有效专属容器继续可用；用户通过系统文件夹选择器授权 iCloud Drive 目录时优先使用该目录，以 security scoped bookmark 持久保存本机权限。容器不可用时给出可执行的选择目录入口，既有备份可独立选择并恢复。授权目录若为本地目录明确标注，不能称为云端已上传。
5. Excel 使用 UIKit 系统文件选择器的通用文件类型打开副本，避免厂商提供方 UTI 识别差异导致置灰。选中后检查扩展名、大小和 XLSX ZIP 实际内容，仍需预览确认导入；取消不报错。
6. 设置增加独立学习阶段入口；学期列表只显示当前阶段。开启下一学期选择已建最新学期之后的首个未建学期；若尾端已建但中间有缺项则补齐最早缺项。仅当阶段所有学期均已创建，才提示开启下一阶段；大学完成后显示已到最后阶段。跨阶段不继承科目，阶段内继承科目但不复制成绩。旧的未归类学期在阶段管理单独列出并可归类。
7. CRUD 反馈不等待小组件完整快照；小组件后台延迟合并更新、序列化和写盘，不让旧任务覆盖新任务。图片查询只读取资源表；用户删除计数使用 SQL 汇总；耗时遮罩延迟出现，短操作不闪烁。弹窗关闭后不再依赖被重置的目标数据。

备选方案：继续修改 XLSX UTI 与专属容器授权无法覆盖重签安装及提供方行为；使用手工遮罩模拟渐进模糊会继续遮挡正文。因此选择系统滚动边缘、通用系统文档选择、用户授权目录。

验收：先复现首次引导缺失与左滑误点；增加阶段推进/范围/继承、目录读写和备份恢复、文档选择器配置的回归测试；运行核心测试、三款 iPhone 模拟器测试与设备 Release 构建，检查引导/左滑/顶部截图。签名设备上的 iCloud 传输状态需要实际账号验证，不把模拟器本地文件测试称为云同步成功。
