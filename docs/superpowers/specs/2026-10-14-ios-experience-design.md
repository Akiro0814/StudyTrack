# 学迹 iOS 体验重构

用户授权：修复壁纸/图表、加入头像、完善首次录入路径，完全按 Apple 思路重写 UI；设计选择由本轮实施决定，不增加确认关卡。

## 方向

采用个人学习手账。比照纯系统 Form（辨识度不足）和重度自绘导航（手势与辅助功能成本高），选择原生 NavigationStack/Tab/Sheet + 独立设计的内容层。系统字体、醒目数字、低饱和底色和强调色，玻璃集中用于操作层；内容区域在壁纸上保持清晰。保留 Reduce Motion / Reduce Transparency / Dynamic Type。

## 页面与路径

- 首页：姓名旁显示可点击头像、学期切换、概览、主录入按钮、最近成绩可点开编辑。无科目时主按钮弹窗引导，创建成功自动继续原来选择的单条/批量流程，取消不触发下一步。
- 科目：独立符号与颜色、记录数、满分；空状态可直接创建，编辑入口、删除确认保留。
- 成绩：紧凑摘要、横向科目筛选、搜索、分组记录、明确空状态、单条/批量新增入口。
- 分析：按考试顺序绘制，而非把同日考试叠在日期轴；保留日期与考试名供选择查看，排名沿用原考试序号并反向显示，缺失不补零；单点可读，长序列保峰谷抽稀。
- 设置：实际 App logo、学迹/StudyTrack/版本、头像档案入口，学习档案/个性化/数据/支持分区。个性化显示实时预览、主题选择、强调色和壁纸更换/移除。
- 编辑：紧凑导航栏、明确字段标签、分数大号输入、可选排名折叠、键盘完成、原草稿/丢弃保护保留。引导页加入品牌和明确下一步。

## 数据与修复

壁纸故障来自 TabView 下的图片被导航容器与 List/Form 默认底色挡住，以及 simple 主题忽略图片。改为共享 AppCanvas，导航容器背景和每个页面内容背景一致；选择照片后不依赖主题。资源仍采用不可变文件与数据库资产索引。

头像在 preferences.platformExtensions.ios.profileAvatars 存储 userID→assetID，使用既有资产/备份机制，不改变 v1 users 字段及 Android 交换结构。验证用户/资源引用；删除用户时清理引用。照片通过 ImageIO 降采样，头像限制 512px，壁纸 2560px；不存入 UserDefaults 或数据库 blob。

## 验证

先加入同日多场/缺失排名/单点/头像备份与无科目录入 UI 回归。通过 Swift Core、三机型模拟器 App/UI、Release IPA；新增带真实图片的 UI 夹具截图检查首页、壁纸、分析和设置，覆盖深色与大字体。真机签名安装和主观触感仍由用户设备验收，不用模拟器截图替代。
